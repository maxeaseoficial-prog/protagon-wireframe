# Protagon Wireframe

OBJETIVO

Criar SOMENTE O ESQUELETO estrutural da landing page do evento “Novo Protagon Cuiabá”.

Esta etapa NÃO é para fazer o design final.

Quero apenas montar corretamente:

- ordem das seções;

- containers;

- textos;

- títulos;

- botões;

- placeholders de imagens;

- espaço da VSL;

- cards básicos;

- FAQ;

- navegação por âncoras;

- responsividade estrutural.

IMPORTANTE:

Não gastar tempo/créditos tentando criar um visual sofisticado nesta etapa.

O design premium será feito depois.

--------------------------------------------------

1. PRINCÍPIO DESTA ETAPA

--------------------------------------------------

Criar uma landing page funcional em formato de WIREFRAME.

Pode usar:

- fundo neutro;

- bordas simples;

- tipografia padrão;

- espaçamentos básicos;

- placeholders cinza para imagens;

- cards simples.

NÃO criar ainda:

- efeitos visuais sofisticados;

- gradients complexos;

- glow;

- partículas;

- texturas;

- animações;

- parallax;

- efeitos 3D;

- fundos elaborados;

- tratamento cinematográfico;

- componentes decorativos complexos.

Não tentar reproduzir agora a arte verde enviada como background.

A identidade visual verde/preto/dourado será aplicada em uma segunda etapa.

16. RESPONSIVIDADE

--------------------------------------------------

Mesmo sendo apenas esqueleto, estruturar corretamente para:

Desktop

Tablet

Mobile

Regras:

- nenhuma rolagem horizontal no body;

- containers com largura máxima;

- imagens responsivas;

- VSL mantendo 16:9;

- cards quebrando de colunas para uma coluna no mobile;

- header adaptável ao mobile;

- CTAs com área de clique adequada;

- conteúdo legível em telas pequenas.
